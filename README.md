# 📸 Media Capture & Storage Web Application  

## 📝 Project Overview  
The **Media Capture & Storage Web Application** is a full-stack solution that enables users to securely upload, manage, and store media files (images and videos). It features user authentication, file handling, and cloud deployment for a seamless experience.  

## 🚀 Features  
### 🔹 **Backend (Node.js, Express, MongoDB)**  
- **User Authentication:** JWT-based secure login and registration.  
- **Media Upload & Management:** Users can upload images/videos using **Multer**.  
- **Storage System:** Media files are stored in a backend folder.  
- **API Endpoints:** RESTful APIs for managing media and user data.  

### 🎨 **Frontend (React.js, Tailwind CSS)**  
- **User-Friendly UI:** Built with **React.js** and styled with **Tailwind CSS**.  
- **State Management:** Implemented **Redux** for managing application state.  
- **Media Display:** Users can view, manage, and delete uploaded media.  

### ☁️ **Deployment & Hosting**  
- **Backend:** Hosted on **Render**  
- **Frontend:** Deployed on **Vercel**  
- **Database:** Managed using **MongoDB Atlas**  

## 🛠️ Tech Stack  
- **Frontend:** React.js, Tailwind CSS, Redux  
- **Backend:** Node.js, Express.js, Multer  
- **Database:** MongoDB (Atlas)  
- **Authentication:** JSON Web Token (JWT)  
- **Deployment:** Render (backend), Vercel (frontend)
